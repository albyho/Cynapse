# JupyterLab Adapter test data

This directory owns runnable Course Package fixtures for the JupyterLab Adapter.
Fixtures here are not Content Packages: they are not published, are not scanned
by `verify:content` by default, and are not referenced by Client tests.

`jupyterlab-operations/` is the manual acceptance course for JupyterLab
Notebook, Cell, Kernel, preview, and terminal operations.
